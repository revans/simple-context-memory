- [Simple Context Memory](https://robertrevans.com/specs/simple-context-memory/): A Claude Code plugin with three slash commands — /opening, /closing, and /report — that give AI sessions structured, decision-focused memory using a surgical shift handoff model so each session starts oriented, not cold. Built by Robert Evans. Covers: what Simple Context Memory is (what-is-this), how each command works (opening-command, closing-command, report-command), the seven-section session archaeology document format (session-anatomy), Roads Not Taken with forward-binding Do Not constraints (roads-not-taken, do-not-constraint), SBAR-C reasoning frame for structured handoffs (sbar-c), three-script compaction protection hooks, the three-horizon architecture — session to note to history (how-it-works), the core problem with memory systems that save everything (problem), and how decision archaeology differs from CogniLayer, /handoff skill, CLAUDE.md, and raw context dumps (differentiation).
